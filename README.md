# Career Quest Atlas

1. Unified Navigation & Pixel-Perfect UI

Unified Header & Layout: Upgrade to the sleek glassmorphism aesthetic from your original layout, featuring a persistent navigation bar with quick links to Explore Roles, My Roadmap, Dashboard, Resume ATS, Mock Interview, and Jobs, along with account sign-in and guest progress status.

Visual Polish: Apply refined design tokens, glowing metric badges, elegant cards, and crisp typography throughout all views.

2. Retain All Current Dynamic Features (No Quiz)

Role Catalog (/explore): 25+ tech and AI roles across 8 domains with demand metrics, salary bands, and trending tools.

Skill-Level Assessment (/roles/$roleId/assess): Self-assessment with Beginner / Intermediate / Advanced depth ratings and real-time readiness scoring (no standardized quiz).

Personalized Roadmap (/roadmap): Phase-by-phase milestone checklist, career readiness gauge, curated learning links, capstone project blueprints, and Markdown/PDF export.

Lovable Cloud Authentication (/auth): Secure email and Google authentication with automatic migration of guest progress to user profiles.

3. Add All Previous Features

Dashboard (/dashboard): Unified career hub showing readiness score, mastered skills, recommended next steps, and quick switches between target roles.

Resume ATS Analyzer (/resume): PDF/DOCX/TXT upload and text extraction, calculating ATS keyword alignment and identifying missing skills against target roles.

Mock Interview Simulator (/interview): Interactive role-specific interview practice with live feedback and STAR-method scoring.

Jobs & Opportunities (/jobs): Curated job listings displaying match percentages, missing prerequisites, and direct application links.

Supporting Services: Restore resume parsing, job listing matchers, and sample student profiles for rapid testing.

4. Zero-Error Compilation

Resolve all TanStack Start route tree and typing inconsistencies so the live preview builds and updates instantly.
